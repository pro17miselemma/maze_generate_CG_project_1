# Maze Generator (Assignment 1 Computer Graphics)

## Description
Generates a rectangular maze using stack and checks that the left hand rule isn't useful in the case. It is generated by beginning with a full grid of columns and rows as walls and then removing northern and eastern walls to create a path.

## Resources used
- Python (by PyCharm IDE)
- Pygame Package

## How to Run
python main.py
